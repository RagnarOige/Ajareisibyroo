# ParadoxkaReisiBüroo

## Idee kirjeldus.

ParadoxkaReisiBüroo on veebipõhine reisibüroo, mis pakub inimestele võimalust reisida erinevatesse ajastutesse. Kasutajad saavad valida sobiva ajastu, tutvuda reisipakettidega, broneerida reisi ning lisada sellele erinevaid lisateenuseid.

Reisivalikus on näiteks Vana-Egiptus ja tulevikuaasta 2100. Veebilehe eesmärk on pakkuda tavapärasest erinevat reisikogemust, kus klient saab avastada ajalugu või näha, milline võiks olla tulevik.

## Funtsioonid.

Reiside valik mille vahel saab valida. Lisateenused. Reiside broneerimine. Detailisem kirjeldus reiside kohta.
